DuoKeys

Project Specification & Developer Handoff Document

Target: iPad / PWA Stack: Next.js + Supabase Hardware: USB-C MIDI Cost: $0/mo Tier

1. Platform Overview & Description

DuoKeys is an interactive web application designed to run seamlessly on an iPad positioned on a piano music stand. Connecting directly to a digital piano via a USB-C MIDI cable, it provides a tailored dual-learning platform for both a 6-year-old child beginner and an adult returning to piano.

Child User Experience (Age 6)

Focused on high-dopamine visual engagement, single-note flashcards ("Note Ninja"), vertical falling-note games, 1–2 measure mini-quests, and immediate audio-visual praise.

Adult User Experience (Parent / Re-learner)

Tailored for analytical practice featuring full MusicXML sheet rendering, A/B measure looping, hands-separate practice controls, BPM speed scaling, and technical exercise generators (Hanon).

4. Detailed Features & Development Roadmap

Phase 1: Core Infrastructure & Web MIDI Engine
Objective: Establish USB-C hardware connectivity, profile switching, and sound generation.
  • P1.1 — Database Schema & Auth Setup Supabase
    Setup profiles (kid/adult toggle), lessons, and progress_logs PostgreSQL tables with Row-Level Security policies.
  • P1.2 — Core MIDI Service (useWebMidi) Web MIDI API
    React hook capturing USB-C device inputs, normalizing noteOn, noteOff, pitch integers (21–108), and velocity values.
  • P1.3 — Sound Sampler & Profile Switcher Tone.js
    Integrate piano soundfont sampler responding to physical keypresses with profile switching in top navigation bar.
Phase 2: Kid Module (Gamified 6yo Experience)
Objective: High-dopamine activities centered around 5-finger scales and note visualizer games.
  • P2.1 — Note Ninja (Flashcard Engine) React Sight Reading Factory
    Single-note flashcards on grand staff with 5-second timers and instant USB-C MIDI note verification.
  • P2.2 — Vertical Falling Notes Engine HTML5 Canvas
    60 FPS canvas displaying colored bars descending toward matching on-screen keys.
  • P2.3 — Wait Mode Engine Event Loop
    Pauses falling note stream at key threshold line until the matching physical key is played.
  • P2.4 — Micro-Quest Song Chunks Supabase Storage
    Songs segmented into 1–2 measure practice levels rewarded with 1 to 3 star ratings based on timing windows (±150ms).
Phase 3: Adult Module (Sight-Reading & Intermediate Practice)
Objective: Standard notation rendering, looping tools, and technical drills for adult re-learning.
  • P3.1 — OSMD MusicXML Renderer OpenSheetMusicDisplay
    Loads and renders vector sheet music with an active auto-scrolling playback cursor.
  • P3.2 — Practice Suite & Looper Tone.js Transport
    Provides A/B measure looping, hands-separate mutes (Bass vs Treble), and tempo adjustment sliders (30%–100% BPM).
  • P3.3 — Technical Drills (Hanon & Algorithmic Sight-Reading) Mutopia Project
    JSON-based loader for Hanon Exercises 1–20 paired with an algorithmic 4-measure melody generator for randomized sight-reading.
Phase 4: Shared & Advanced Features (Co-Op & Analytics)
Objective: Joint parent-child activities, session recordings, and long-term practice tracking.
  • P4.1 — Duet Mode (Split Keyboard) Custom Logic
    Splits 88 keys into Zone A (Kid: Treble keys 56–108) and Zone B (Parent: Bass keys 21–55) for simultaneous four-hand score evaluation.
  • P4.2 — MIDI Session Recorder Supabase Storage
    Captures note-on/off events and timing offsets to save recorded performances for playback review.
  • P4.3 — Practice Dashboard & Streak Logger Recharts
    Displays weekly bench time, active daily streaks, and accuracy growth graphs per profile.

5. Development Execution Plan for Claude Code

  1. Sprint 1 (Infrastructure): Initialize Next.js PWA repository, configure Supabase tables/client, and build the core useWebMidi hook.
  2. Sprint 2 (Kid Core): Develop the HTML5 Canvas vertical falling-notes renderer, build "Wait Mode" mechanics, and create the "Note Ninja" flashcard component.
  3. Sprint 3 (Adult Core): Integrate OpenSheetMusicDisplay, construct the A/B measure looper and tempo UI, and load the Hanon drill dataset.
  4. Sprint 4 (Polishing & Duet): Implement split-keyboard evaluation for Duet Mode, set up MIDI recording to Supabase Storage, and finalize the shared dashboard.
