The nine decisions everything rests on

Each is closed. Reopening one is a deliberate act, not a drift — every component in the architecture cites the decision it descends from.

ADR-001

Desktop browser, not iPad

The Web MIDI API is not implemented in Safari or any WebKit-backed browser on any platform — WebKit bug #107250 has been open since January 2013 with no roadmap. This is a different thing from native CoreMIDI, which iOS has had since 2010 and which is what GarageBand and every other iPad MIDI app uses. A web app on iPad cannot reach the piano; a native app can. Build on a Windows laptop in Chrome or Edge.

ADR-002

Keep the iPad door open at near-zero cost

Two constraints the architecture wants anyway preserve the path: all MIDI through the single MidiBackend port, enforced by a lint rule; and no Next.js server-only features on the runtime path. Extension later is a Capacitor shell plus a Swift CoreMIDI plugin — 90–95% of the code transfers unchanged. Blocker to note now: Xcode is macOS-only, so iOS builds need a rented or cloud Mac. Arrange it before Sprint 5, not during.

ADR-003

Local-first storage, cloud sync additive

Practice happens wherever the piano is, often on the worst Wi-Fi in the house; a spinner between "sit down" and "play" kills the habit faster than any missing feature. IndexedDB is the source of truth, every practice feature works offline, and content ships as static JSON needing no database at all.

ADR-004

Cloud sync is built in Sprint 2, not deferred

Revises the earlier "optional, Sprint 4" position. The failure mode being guarded against is a lost or reset laptop taking a year of progress with it. The Supabase project is created in Sprint 1 so the seven-day free-tier pause clock never becomes a surprise; auth and the outbox land in Sprint 2 alongside profiles.

ADR-005

Pure core, thin adapters

core/ holds the clock, matcher, grader and progression as pure TypeScript with zero imports from React, the DOM, Web MIDI, Web Audio, IndexedDB or Supabase. This is the single decision that lets CI test the hard parts with no piano, no audio hardware and no six-year-old.

ADR-006

The audio clock is master

AudioContext.currentTime is canonical; wall time is corrected toward it via an EMA. Grading against the wall clock while sounding against the audio clock accumulates drift that surfaces as "the app says I'm late and I know I wasn't."

ADR-007

Tempo-relative tolerance with an absolute floor

The original flat ±150 ms is a generous ninth of a beat at 60 bpm and nearly half a beat at 160, where it grades a wrong subdivision as correct. Instead: max(floorMs, beatMs × fraction) per tier, scaled by 1.6 for the child.

ADR-008

Follow mainstream beginner pedagogy

No lessons are booked, but the app should not invent a teaching order that would conflict if they start. Difficulty 1–5 maps onto the four stages Faber, Alfred and Bastien broadly agree on: pre-staff five-finger at middle C → neighbouring positions → landmark-note reading → full grand staff. Re-keying to a specific book later is a lookup table, not a rewrite.

ADR-009

88 keys, sustain pedal, class-compliant USB

Full range confirmed, so no content filtering or forced transposition is needed. keyboardRange stays in the profile as a safety net for a future second instrument.

The rule that makes tuning safeGolden fixtures are recorded real performances replayed through decode → pedal → matcher → grade, asserting the exact resulting grade. Any change to the tolerance constants must come with deliberate, reviewed updates to their expected values. A silent fixture update in a diff is a review blocker.

Definition of Done

A story is done when all nine hold. No partial credit.

#Condition
1Acceptance criteria in the story are met
2The TS-* scenarios the story references pass
3Coverage targets for any touched core/ module still hold
4Boundary lint passes — no platform import in core/, no ui/ import in adapters/
5TypeScript compiles under strict and noUncheckedIndexedAccess, with no any added
6The feature works with the network off, unless it is itself a sync feature
7If it touches the render loop, a five-minute session holds 60 fps
8If it touches tolerance or grading, golden fixtures are updated deliberately and reviewed
9It has been played at the actual piano at least once

That last one is not ceremony. A grading change that passes every fixture and feels wrong under the hands is still wrong.
